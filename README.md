# mTalha

Website source for mTalha — my personal developer portfolio, showcasing web/mobile/cloud/security projects.

## Stack

React + Vite, React Router, plain CSS (no UI framework).

## Development

```
npm install
npm run dev
```

## Build

```
npm run build
```

## Deployment

Continuous deployment via Netlify from the `main` branch — every push
to `main` triggers a production build and deploy to
[mtalha.is-a.dev](https://mtalha.is-a.dev).
